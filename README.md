# 🛠️ The Creator AI – VS Code Extension

**The Creator AI** adds an AI coding assistant directly into your **Visual Studio Code** editor to help you write, understand, and plan your code faster.

## ✨ What This Extension Can Do

* **Pick Your Context**: Easily select the files or folders that the AI should pay attention to. You do this through a simple user interface — no need to edit config files.

* **Plan Code Changes with AI**: Tell the AI what changes you want to make in your code. It will generate a step-by-step plan to help you implement those changes.

---

## 🔑 Requirements

Before you can use Creator AI, you’ll need an **API key** from either:

* [OpenAI](https://platform.openai.com/)
* [Gemini (Google AI)](https://aistudio.google.com/app/apikey)

> When you run the extension for the first time, it will ask you to enter your API key.

---

## 🚀 Getting Started

1. **Install** this extension from the VS Code Marketplace.
2. Open any project folder in VS Code.
3. Click the Creator AI icon in the sidebar.
4. Add your API key when prompted.
5. Start using the assistant to get help or plan code changes!
